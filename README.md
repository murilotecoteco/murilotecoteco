## Projetos em destaque

### [MGMOTORS](https://github.com/murilotecoteco/MGMOTORS)

Marketplace web de veículos com autenticação, PostgreSQL, RLS, Storage privado, chat em tempo real, painel administrativo e deploy no Vercel.

**Stack:** `HTML` `CSS` `JavaScript` `Supabase` `PostgreSQL` `Vercel`

[Demo](https://mgmotorss.vercel.app/MG-INICIO/inicio.html)

---

### [Academia com Pagamentos (Gym Membership Payments)](https://github.com/murilotecoteco/gym-membership-payments)

Projeto prático de assinaturas para academias, com Stripe Checkout, webhooks, validação de pagamentos, testes automatizados e Supabase.

**Stack:** `Node.js` `Express` `Stripe` `Supabase` `PostgreSQL`

[Demo](https://academia-com-pagamentos.onrender.com/)

---

### [Solar CME Monitor](https://github.com/murilotecoteco/cme-dashboard)

Dashboard para monitoramento de ejeções de massa coronal usando a API DONKI da NASA e uma Edge Function do Supabase.

**Stack:** `React` `JavaScript` `TypeScript` `Supabase` `NASA DONKI API`

[Demo](https://solar-cme-monitor.vercel.app/)

---

### [Task Manager](https://github.com/murilotecoteco/task-manager-nextjs-react)

Aplicação de gerenciamento de tarefas com Next.js, React, TypeScript, persistência local, filtros, estatísticas e interface responsiva.

**Stack:** `Next.js` `React` `TypeScript` `Tailwind CSS`

[Demo](https://gerenciador-de-tarefas-one-pearl.vercel.app/)
